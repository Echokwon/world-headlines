# 지구 한 장

사이트: https://echokwon.github.io/world-headlines/1024/

세계 뉴스 헤드라인을 모아 보는 반응형 단일 페이지입니다.

- 지역/주제 필터, 제목/언론사 검색, 시간순 정렬, 더 보기
- 기사 저장: 현재 브라우저에 저장
- BBC / The Guardian 공개 RSS에서 제목, 링크, 발행 시각, 이미지 메타데이터 수집
- 제목은 원문 언어로 제공하며 원문 기사는 새 탭으로 열립니다.
- 연결 실패 안내와 오래된 데이터 안내

## 로컬 실행
저장소 루트에서 `python -m http.server 8000` 실행 후 http://localhost:8000/1024/ 에 접속합니다.

## 뉴스 수집 및 배포
`python 1024/update_news.py`로 RSS를 수집합니다. Python 표준 라이브러리만 사용합니다. 수집에 모두 실패하면 기존 파일을 보존하며 명령은 실패 상태로 종료됩니다.

저장소 루트 `.github/workflows/news.yml`은 main 브랜치 변경, 수동 실행, 매시간 예약 실행 시 뉴스를 수집하고 GitHub Pages에 배포합니다. 수집 결과는 배포 산출물에 포함되며 저장소의 JSON 파일에는 자동 커밋하지 않습니다. Pages의 Source는 GitHub Actions입니다.

GitHub 예약 작업은 지연되거나 비활성 저장소에서 중지될 수 있어 실시간 갱신을 보장하지 않습니다. 화면의 새로고침 버튼은 마지막으로 배포된 데이터를 다시 읽습니다.

RSS 이미지와 기사의 저작권은 원 언론사에 있습니다. 이미지는 원 제공처 서버에서 로드하고 연결 실패 시 대체 그래픽을 표시합니다. Google Fonts 연결 실패 시 시스템 글꼴을 사용합니다.
