# 지구 한 장

세계 뉴스 헤드라인을 모아 보는 반응형 단일 페이지입니다.

- 지역/주제 필터, 제목/언론사 검색, 시간순 정렬, 더 보기
- 기사 저장: 현재 브라우저에 저장
- BBC / The Guardian RSS에서 제목, 링크, 발행 시각, 이미지 메타데이터만 수집
- 제목은 원문 언어 그대로 표시하며 원문 기사는 새 탭으로 열립니다.
- 뉴스 수집 실패 시 기존 데이터를 보존하고, 3시간 이상 지난 데이터에는 지연 안내를 표시합니다.

## 로컬 실행
저장소 루트에서 `python -m http.server 8000`을 실행한 뒤 http://localhost:8000/1024/ 에 접속합니다.

## 데이터 갱신
`python 1024/update_news.py`

Python 표준 라이브러리만 사용합니다. 저장소 루트 `.github/workflows/news.yml`에서 1시간마다 수집합니다. GitHub 예약 실행은 지연되거나 비활성 저장소에서 중지될 수 있습니다. 새로고침 버튼은 마지막으로 수집된 데이터를 다시 불러옵니다.

## 배포
GitHub Pages의 배포 원본을 main 브랜치 / (root)로 설정하면 /1024/에서 볼 수 있습니다.

RSS 이미지는 원 제공처 서버에서 로드되며 연결 실패 시 그래픽으로 대체합니다. 이미지와 기사 저작권은 원 언론사에 있습니다. Google Fonts 연결 실패 시 시스템 글꼴로 표시합니다.
